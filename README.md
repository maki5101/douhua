# 豆花儿

把手机屏幕当成触控板和键盘，手势参照 Mac 触控板，带震动反馈、打字面板和数字键盘，三指 / 四指手势、触控板四个角上的按钮都能自己设定。
两种用法：**桌面模式**控制这台手机自己——它接的外接屏（三星 DeX、XREAL 眼镜……），或者分屏里另一边的应用（比如 Moonlight 串流）；
**蓝牙模式**当蓝牙键盘鼠标，控制电脑、平板、电视（任何 Android 13 以上、系统支持的手机都行，不用服务）。

最初是用来替代三星 DeX 自带的"手机当触控板"：左手捧着手机，左边一竖条按钮给拇指按，右边整块是触控板，横屏竖屏都自动排布。界面纯黑，只有按钮和触控板的暗灰边框（屏幕要一直亮着，黑色省电）。

**桌面模式下，豆花儿在前台时会接管这块屏的触摸**（和三星 DeX 自带触控板全屏时一样）：下拉通知栏、边缘返回这些系统手势用不了，横幅通知点不了（分屏 / 小窗时只管豆花儿自己那块：另一边的应用、分隔条、从屏幕边缘起手的系统手势照常能用）。离开豆花儿的办法：

- 触控板顶上正中 ⋯ 菜单里的 **退出**（默认左上角的小按钮也是退出）
- 按电源键
- 打开设置页、打开贴字面板时会自动把触摸还给系统
- 豆花儿卡住超过 3 秒，服务也会自动把触摸还给系统

## 两种连接方式

设置最上面选（默认本机）：

- **本机**：控制这台手机和它接的屏幕——外接屏（三星有线 / 无线 DeX、XREAL 眼镜……），或者手机自己分屏时的另一边（比如 Moonlight 串流）。
  不是三星专用，但目前只在三星手机上用过：服务靠系统输入信息里的坐标换算矩阵找触摸屏，有的手机没有这一项，会找不到。
  要豆花儿服务：配对一次后手机自己就能启动（见下面"不用电脑：手机自己启动服务"），也可以照旧用电脑 adb 启动。
- **蓝牙**：手机当成一个普通的蓝牙键盘 + 鼠标，控制电脑、平板、电视。不用服务，第一次打开时允许"附近的设备"权限。
  1. 设置 → 连接方式选"蓝牙"，点"配对新设备"，系统会问能不能让别的设备搜到这台手机，允许。
  2. 在电脑 / 平板 / 电视的蓝牙设置里添加设备，选这台手机，两边确认配对。**配对时豆花儿要开着**。
  3. 连上后触控板底部显示"蓝牙：设备名"。以后打开豆花儿会自动连上次那台；换一台在设置的"连哪台设备"里选。

  以前配对过的设备（比如传过文件），要先在两边都删掉配对再重新配，否则对方认不出这台手机是键盘鼠标。

  蓝牙模式下的不同：
  - 手势、整屏键盘、震动、按钮都一样；对方看到的是普通键盘鼠标，缩放靠 Ctrl + 滚轮（浏览器、多数电脑软件都认）。
  - 返回、主屏、播放暂停、音量走蓝牙的标准媒体键；最近任务、所有应用、通知栏没有通用的键，用不了；贴字的"发送"用不了（剪贴板在手机上），"打出来"能用。
  - 触摸不再被服务接管：从屏幕左右边缘往里划不会触发系统的返回（豆花儿请系统让开了），从底边往上划还是回桌面。
  - 旋转：电脑那边的服务开着时照常；没开服务时请求系统转屏，一般手机管用，三星外屏这类忽略应用方向请求的屏转不了。

## 语言

中文、日文、韩文、英文、法文、德文、意大利文、西班牙文、阿拉伯文，跟随系统语言；系统语言不在其中时显示英文。
也可以只给豆花儿单独选语言：系统设置 → 应用 → 豆花儿 → 语言。阿拉伯文下界面从右往左排（键盘和数字键盘按实体键盘排，不镜像）。

## 手势

| 手势 | 动作 |
|---|---|
| 单指移动 | 移动光标 |
| 单指轻点 | 左键 |
| 双指轻点 | 右键 |
| 轻点一下，马上再按住移动 | 拖动，松手结束 |
| 单指按住不动一会儿（震一下） | 按下左键，接着移动就是拖动，松手结束（时长可调） |
| 轻点两下 | 双击 |
| 双指上下 / 左右滑 | 滚动 |
| 单指在触控板左右边缘（浅线外侧那一条）上下滑 | 竖向滚动 |
| 单指在触控板上下边缘左右滑 | 横向滚动（四个角两种都算，看你往哪个方向滑） |

边缘带里轻点仍是单击。滚动每滚一格会"咔嗒"震一下，像转滚轮（设置里可选：关 / 只在边缘滚动时 / 所有滚动，默认所有滚动）。
触控板铺满整块屏幕、贴着屏幕边缘，边缘带就在机身边框旁边，摸着边就能找到。
| 双指张开 / 捏合 | 放大 / 缩小（按住 Ctrl 滚滚轮，浏览器等桌面应用都认；可在设置里关掉） |
| 三指 / 四指：轻点、上滑、下滑、左滑、右滑 | 在设置里自己选（默认见下） |

三指默认：轻点 = 返回，上滑 = 最近任务，下滑 = 主屏幕，左滑 / 右滑 = 切换应用。四指默认：轻点 = 应用列表，其余空着。

点击、拖动开始和结束、三指 / 四指手势都会震一下，强度在设置里调（关 / 小 / 中 / 大）。

## 主界面的按钮

默认只有触控板和它四个角上的小按钮：左上 = 退出、右上 = 旋转、右下 = 键盘、左下 = 数字（都能在设置 → 触控板里换，设成"无"就不放）。
触控板顶上正中有个 ⋯（不带框，强调色，换哪套主题都显眼），点开是 键盘 / 设置 / 旋转 / 退出；键盘界面的小触控板上也有一个（菜单项多几个，见下面）。
点菜单外面、或者按返回，只关菜单。

另有**自定义按键**（以前的左侧按钮条）：设置 → 按钮与按键里打开（默认关），触控板左边多一竖条按钮，个数可以加减（最多 12 个），
默认是 旋转、键盘、数字、返回、复制、粘贴、撤销、左键。屏幕矮（横屏）放不下时自动分成两列。

- **旋转**：横竖屏切换，整块屏真的转过去（和系统导航栏的旋转建议按钮一样，自动旋转关着也能用）。
  竖转横时朝哪边看你当时手机怎么拿的。选的方向会记住，下次打开豆花儿自动转过去；退出豆花儿时恢复你原来的方向锁定。
- **键盘**：切到键盘界面（整屏，键盘和小触控板占满）。豆花儿打开时系统里多了一个"USB 键盘"（Douhua Keyboard），
  系统把它当真键盘：长按连发、快捷键都是原生的。
  - 字母区照 Gboard 排；上面一排是 Esc Tab Shift Ctrl Alt Win Caps Fn Del，再下面是数字行；底下是"符 ，空格 。↵"，
    最下面一排快捷键：复制 粘贴 剪切 撤销 全选 ← ↑ ↓ →。
  - Ctrl / Alt / Win / Shift 和真键盘一样：按下马上发，按住它再点别的键就是组合键（按住 Shift 点 a = A），松手就松；
    单独点一下就是点了一下（主机上"单点 Shift 切中英文"照常；Windows 上单点 Alt 会激活菜单栏、单点 Win 打开开始菜单，同真键盘）。
    要锁住时单独按住 0.4–1 秒再松手（到 0.4 秒震一下、键高亮），打完下一个键自动解开，再点一下锁住的键也解开；按住超过 1 秒高亮退回、松手不锁。
    按着期间点过别的键、点过鼠标、滚过滚轮、缩放过，都不锁。锁住或按着 Shift 时键帽变大写、数字行变 `!@#…`。
    上面一排的 Shift 和字母区的 ⇧ 是同一个键，切到符号页、Fn 页时也能用它（Shift + 方向键、Shift + F 键）。
  - Caps：点一下 = 给主机发一次大写锁定，键高亮、字母键帽变大写；按住 0.4 秒 = 只切豆花这边的显示、不发给主机
    （豆花看不到主机的大写灯，显示和主机对不上时按住一下对回来；换了主机显示归"关"）。
  - 按字母、数字、符号键时，键的正上方会浮出放大的字，看清按到了哪个。
  - **⋯ 菜单**：小触控板顶上正中有个 ⋯（离屏幕边至少 20dp，拿手机时不容易碰到）；小触控板关着时 ⋯ 在上面一排的最右边（强调色的键帽，一眼找得到）。
    点开是"收起键盘 / 调整大小 / 布局 / 指点 / 设置 / 旋转 / 退出"："布局"点一下在 自动 → 分裂 → 合并 之间换（菜单不关，可以连着点），
    "指点"在 触控板 → 小红点 → 关 之间换。点菜单外面、或者按返回，只关菜单。窗口矮放不下一列时菜单自动分成两列。
  - **小红点**（模拟 ThinkPad）：按住往哪边推，光标就往哪边走，推得越远越快，松手就停；轻点红点 = 左键。照 ThinkPad 键盘摆：
    红点嵌在键盘中间（G、H、V、B 交界），分裂键盘时放在两半中间、只占一窄列，两半更宽；键盘最下面多一排左 / 中 / 右键：
    左键按住 + 推红点 = 拖动；按住中键推红点 = 滚动，没滚过就松开 = 中键单击。
    小红点状态下最下面一排是"符 [，。] 空格 │ 左 中 右 │ 空格 ↵"：逗号句号合成一个键（点一下逗号，按住 0.4 秒句号、震一下），右手边也有空格。
    设置 → 触控板里能调灵敏度，也能让主界面和键盘页的触控板上沿 / 下沿多一排左 / 中 / 右键。
  - 最下面一排 9 个位置都能在设置里换（同一份动作清单，也能放"返回""键盘界面"这类）。
  - "符"切到符号页（`! @ # - _ = + [ ] { } \ | ; : ' " ~ < > ? /` 一按就出），"Fn"切到 F1–F12、Home / End / 翻页。
  - **调整大小**：拖键盘的上下左右边改大小、拖中间挪位置，横竖屏各记一份；"恢复默认"回到初始大小。
    拖动有轻微对齐：明显上下拖就只上下动、明显左右拖就只左右动；靠近居中 / 屏幕边缘会轻轻吸一下（震一下提示），继续拖就能拖过去；
    调整时屏幕上方（键盘挪到上面时是下方）临时出现"完成 / 恢复默认"，调完点"完成"。
    键盘上方空出来的地方是小触控板，打字中间不用收起键盘也能点、能挪光标。
  - **分裂键盘**：键盘页又宽又矮时（大屏分屏的下半边、手机横屏，宽是高的两倍以上），键盘自动分成左右两半，
    小触控板放在中间：左半 `q w e r t / a s d f g / ⇧ z x c v`，右半 `y u i o p / h j k l / b n m ⌫`，两边各有一个空格。
    窗口变窄就自动合回一整块；⋯ 菜单的"布局"可以固定成分裂或合并。分裂时"调整大小"两半对称着调：拖任一半的内侧边两半一起变宽变窄（中间的触控板跟着变），
    拖外侧边一起往里收，拖上下边一起变高变矮，拖中间一起上下挪；分裂和整块的大小各记一份，"恢复默认"只恢复眼下这种。
  - **打中文**靠接收那边的输入法（和插真键盘一样；桌面模式是手机上的，蓝牙模式是对方设备上的）：要用支持外接键盘拼音的输入法，比如 Gboard。
- **数字**：数字键盘，也走这块虚拟键盘。
- **贴字**（默认没放在哪个按钮上，可在设置里分配）：用手机自己的输入法（语音、中文）打一句，按"发送"贴进正在输入的地方。
  原理是先复制到剪贴板再按 Ctrl+V，所以**会覆盖剪贴板原来的内容**；蓝牙模式下没有"发送"（剪贴板在手机上，到不了对方）。贴字面板开着时触控板暂停（输入法要用触摸）。
  面板上另有"**打出来**"：不经剪贴板，按设置 → 键盘里实体键盘的语言和模式找每个字在哪个键，一个键一个键匀速打过去
  （BIOS、没装剪贴板同步的机器、蓝牙模式都能用；速度在设置 → 键盘最下面调，主机要设成同一种布局）。蓝牙模式下面板上的 ⌫ ↵ Tab 也是真键盘的键。打不出的字（中文、emoji）会跳过并数出来；
  随时能按"停止"，断开、退后台、收起面板也停，停了不会自己接着打，也不会自己补回车。桌面模式下要分屏用（豆花儿和接字的应用各一半）。
- **左键**：按住期间鼠标左键一直按着，配合右手移动就是拖动（像笔记本的实体按键）。

**所有能自定义的位置共用同一份动作清单**：触控板四个角上的小按钮、自定义按键、
三指 / 四指手势、键盘最下面一排、音量键。清单里有返回、主屏幕、最近任务、切换应用、显示桌面、截屏、复制粘贴撤销、网页前进后退、
开关标签页、方向键、媒体键、键盘界面、数字键盘、旋转、退出等，最后一项"自定义组合键"可以自己勾 Ctrl / Shift / Alt / Super 再挑一个键。

## 安装和启动

需要：电脑上有 adb，手机开了无线调试（或 USB 调试）并已连上。连着多台手机时，脚本会列出来让你选；也可以加 `-s <序列号>`，或者先指定：

```bash
export ANDROID_SERIAL=<手机的 adb 序列号或 IP:端口>
```

第一次装（编译需要 Android SDK，放在项目的 `.sdk/` 下，见 `tools/build.sh` 的报错提示）：

```bash
tools/build.sh --install
```

它会编译、装到手机、并在手机上拉起豆花儿服务。**手机重启后服务会没掉**，要再运行一次：

```bash
tools/start-server.sh
```

服务已经在运行时它会先检查一下：服务卡住了（端口不接连接）就自动重启，正常就什么都不做；要强制重启加 `--restart`。

### 不用电脑：手机自己启动服务

豆花儿可以借手机自带的"无线调试"自己拉起服务，不用电脑，也不用装 Shizuku。只需要配对一次：

1. 打开豆花儿 → 设置，最上面一节"豆花儿服务"逐项显示要满足的条件，哪项没满足就点它下面的按钮直接去系统里对应的页面：
   - **连着 Wi-Fi**（无线调试只能在 Wi-Fi 下打开；只用移动数据或自己开热点时不行）
   - **开发者选项**：关于手机 → 软件信息 → 连点"编译编号"7 次（其他手机多半是"版本号"）
   - **USB 调试**：开发者选项里打开。服务靠它活着——**关掉 USB 调试或开发者选项，服务会停掉**；三星的"自动拦截器"会关掉 USB 调试
2. 点"开始配对"，豆花儿会带你到开发者选项：打开"无线调试"，点进去选"使用配对码配对设备"。
   第一次在某个 Wi-Fi 上打开时系统会问"是否允许在此网络上使用无线调试"——**"始终允许"只在自己家里或信得过的 Wi-Fi 上选**（见下面）。
3. 下拉通知栏，在豆花儿的通知里输入屏幕上的 6 位配对码（配对窗口一离开就关，所以在通知里输，不用切回豆花儿）。
4. 配对成功后豆花儿马上启动服务，并打开"自动启动服务"：以后打开豆花儿时服务没在跑就自动启动，手机重启后连上 Wi-Fi 也会自动启动。
   配对时你自己打开的无线调试，豆花儿不会替你关（你的电脑可能正通过它连着手机），通知里会提醒你不用时关掉、带一个跳过去的按钮。

几点说明：
- 第一次启动时豆花儿会给自己授权"修改安全设置"，之后无线调试关着它也能自己打开、启动完马上关掉（你自己开着的它不动）。
- 在某个 Wi-Fi 上第一次打开无线调试时，系统会问"是否允许在此网络上使用无线调试"。**只在自己家里或信得过的 Wi-Fi 上选"始终允许"，
  咖啡馆、公司、酒店这类公共网络别选**：选了的网络上，以后豆花儿拉起服务时会把无线调试打开几秒，这几秒里同一个网络的设备能看到它开着；
  连进来要有配好的密钥或配对码，但 2026 年 5 月才修过一个能绕过这道验证的漏洞（CVE-2026-0073）。
- 自动启动（打开豆花儿时、开机后、豆花儿更新后）碰到系统弹了这个框、3 分钟内没被允许，就先暂停：不再自己去打开无线调试，免得到处弹窗
  （豆花儿不读 Wi-Fi 名称，分不清是哪个网络）。暂停期间无线调试本来开着时照常自动启动；在设置页手动点"启动服务"成功一次就恢复，设置页里也会写明。
- 无线调试是你自己开着的（不是豆花儿临时打开的），设置页"无线调试"那一项会提醒你不用电脑连手机时关掉、公共网络上尤其要关。
  关掉不影响已经在跑的服务（只要 USB 调试开着）。
- 配对过的密钥 7 天不用会被系统作废，到时设置页会提示重新配对，再配一次就好。
- 豆花儿的调试密钥加密存在手机里，只用来连这台手机自己。

然后在手机上打开"豆花儿"。第一次打开会问能不能发通知——允许之后，**每次接上外接显示器（三星有线 / 无线 DeX、XREAL 眼镜……）
都会弹一条通知，点一下就在手机上打开豆花儿**，拔掉显示器通知自动消失（和三星自带触控板的通知一样）。
三星自己的那条通知要是嫌重复，可以在系统通知设置里把它关掉。

触控板底部那行字是状态：

| 状态 | 意思 |
|---|---|
| XREAL One（或你的显示器名） | 一切正常，触摸已接管 |
| 没找到外接屏… | 触摸已接管，但没接外接屏：按键发给当前焦点（手机自己分屏用时就是这样） |
| 正在接管触摸屏…… | 刚打开，稍等 |
| 贴字中 · 触控板暂停 | 贴字面板开着 |
| 豆花儿服务没在运行：点这里在手机上启动… | 服务没起（多半是手机重启过）。点一下去设置页启动；开着"自动启动服务"时豆花儿会自己先试 |
| 豆花儿服务没响应：点这里重启… | 服务卡住了，点一下去设置页重启，或在电脑上运行 tools/start-server.sh（会认出来并自动重启）（蓝牙模式下接在蓝牙状态后面） |
| 正在启动豆花儿服务… | 手机正在自己拉起服务 |
| 豆花儿服务正被另一个连接占用… | 另一个豆花儿窗口或测试工具正连着服务，它断开后自动接上 |

打正式安装包（发给别人装的）：

```bash
tools/package.sh
```

要求先提交（只从最新提交构建），产物在 `dist/douhua-<版本>.apk`，用正式密钥签名、不可调试。
正式签名的密钥库放 `.private/release.keystore`，口令写在 `.env`（模板 `.env.example`），这两样都不进 git，**要自己备份**。
没提交时可以用 `tools/package.sh --snapshot` 试打包。调试版和正式版签名不同，手机上换装要先卸载。

其它脚本：

| 命令 | 作用 |
|---|---|
| `tools/start-server.sh --debug` | 拉起服务并每秒记一行鼠标包统计（查卡顿用），日志在手机 `/data/local/tmp/douhua-server.log`（上一次的是 `.prev`） |
| `tools/start-server.sh --restart` | 不管服务看着正不正常，强制重启 |
| `tools/stop-server.sh` | 停掉服务（触摸屏释放、虚拟鼠标移除）；3 秒左右不退出就强制结束 |
| `tools/selftest.sh` | 不开界面测 App 能不能连上服务（屏幕灭着时系统会断后台网络，测不准） |
| `tools/test.sh` | 离线测试（手势识别、触摸分流、HID 报文、多点触控解码、触摸屏查找） |

## 注意

- 用三星 DeX 时，DeX 设置里的"指针流向手机屏幕"保持**关闭**。开着时虚拟鼠标在 DeX 和手机屏之间切换，有卡死重启的已知问题（scrcpy 社区报告过同样的情况）。
- 豆花儿打开时，系统里会多出一个叫 Douhua Touchpad 的 USB 鼠标和一个叫 Douhua Keyboard 的 USB 键盘；关掉豆花儿它们就消失。
- 为什么要接管触摸：手机上开着带"执行手势"权限的无障碍服务（比如 Tasker）时，系统规定同一时刻只认一个输入设备，
  手指和虚拟鼠标会互相打断，光标一卡一卡。接管后系统里只剩虚拟鼠标一个设备。
- 豆花儿申请了"网络"权限，只用来连本机 127.0.0.1 上的豆花儿服务和手机自己的无线调试（找端口用的是局域网里的 mDNS 广播，只认这台手机自己的），不上网。
- "附近的设备"权限只在蓝牙模式下用：连配对过的设备、配对新设备时让别的设备搜到这台手机。
