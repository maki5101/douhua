# 豆花

把三星手机的屏幕当成 DeX 的触控板，手势参照 Mac 触控板，带震动反馈、打字面板和数字键盘，三指 / 四指手势和左侧按钮都能自己设定。

用来替代 DeX 自带的"手机当触控板"：左手捧着手机，左边一竖条按钮给拇指按，右边整块是触控板，横屏竖屏都自动排布。界面纯黑，只有按钮和触控板的暗灰边框（屏幕要一直亮着，黑色省电）。

**豆花在前台时会接管这块屏的触摸**（和三星自带触控板全屏时一样）：下拉通知栏、边缘返回这些系统手势用不了，横幅通知点不了。离开豆花的办法：

- 左侧最上面的 **退出** 按钮
- 按电源键
- 打开设置页、打开贴字面板时会自动把触摸还给系统
- 豆花卡住超过 3 秒，服务也会自动把触摸还给系统

## 语言

中文、日文、韩文、英文、法文、德文、意大利文、西班牙文、阿拉伯文，跟随系统语言；系统语言不在其中时显示英文。
也可以只给豆花单独选语言：系统设置 → 应用 → 豆花 → 语言。阿拉伯文下界面从右往左排（键盘和数字键盘按实体键盘排，不镜像）。

## 手势

| 手势 | 动作 |
|---|---|
| 单指移动 | 移动光标 |
| 单指轻点 | 左键 |
| 双指轻点 | 右键 |
| 轻点一下，马上再按住移动 | 拖动，松手结束 |
| 单指按住不动一会儿（震一下） | 按下左键，接着移动就是拖动，松手结束（时长可调） |
| 轻点两下 | 双击 |
| 双指上下 / 左右滑 | 滚动 |
| 单指在触控板左右边缘（浅线外侧那一条）上下滑 | 竖向滚动 |
| 单指在触控板上下边缘左右滑 | 横向滚动（四个角两种都算，看你往哪个方向滑） |

边缘带里轻点仍是单击。滚动每滚一格会"咔嗒"震一下，像转滚轮（设置里可选：关 / 只在边缘滚动时 / 所有滚动，默认所有滚动）。
触控板铺满整块屏幕、贴着屏幕边缘，边缘带就在机身边框旁边，摸着边就能找到。
| 双指张开 / 捏合 | 放大 / 缩小（按住 Ctrl 滚滚轮，浏览器等桌面应用都认；可在设置里关掉） |
| 三指 / 四指：轻点、上滑、下滑、左滑、右滑 | 在设置里自己选（默认见下） |

三指默认：轻点 = 返回，上滑 = 最近任务，下滑 = 主屏幕，左滑 / 右滑 = 切换应用。四指默认：轻点 = 应用列表，其余空着。

点击、拖动开始和结束、三指 / 四指手势都会震一下，强度在设置里调（关 / 小 / 中 / 大）。

## 左侧按钮

从上到下：退出、旋转、设置（这三个固定），然后 7 个可自己设定的位置，默认是 键盘、数字、返回、复制、粘贴、撤销、左键。屏幕矮（横屏）放不下时自动分成两列。

- **旋转**：横竖屏切换，整块屏真的转过去（和系统导航栏的旋转建议按钮一样，自动旋转关着也能用）。
  竖转横时朝哪边看你当时手机怎么拿的。选的方向会记住，下次打开豆花自动转过去；退出豆花时恢复你原来的方向锁定。
- **键盘**：切到键盘界面（整屏），顶上是"收起键盘"和"调整大小"。豆花打开时系统里多了一个"USB 键盘"（Douhua Keyboard），
  DeX 把它当真键盘：长按连发、快捷键都是原生的。
  - 字母区照 Gboard 排；上面一排是 Esc Tab Ctrl Alt Win Caps Fn Del，再下面是数字行；底下是"符 ，空格 。↵"，
    最下面一排快捷键：复制 粘贴 剪切 撤销 全选 ← ↑ ↓ →。
  - Ctrl / Alt / Win / ⇧ 点一下锁定（键高亮），打完下一个键自动解开；锁定 ⇧ 时键帽变大写、数字行变 `!@#…`。
  - 最下面一排 9 个位置都能在设置里换（同一份动作清单，也能放"返回""键盘界面"这类）。
  - "符"切到符号页（`! @ # - _ = + [ ] { } \ | ; : ' " ~ < > ? /` 一按就出），"Fn"切到 F1–F12、Home / End / 翻页。
  - **调整大小**：拖键盘的上下左右边改大小、拖中间挪位置，横竖屏各记一份；"恢复默认"回到初始大小。
    拖动有轻微对齐：明显上下拖就只上下动、明显左右拖就只左右动；靠近居中 / 屏幕边缘会轻轻吸一下（震一下提示），继续拖就能拖过去；
    "工具栏放下面 / 上面"把"收起键盘 / 调整大小"这条移到屏幕底部或顶部。
    键盘上方空出来的地方是小触控板，打字中间不用收起键盘也能点、能挪光标。
  - **打中文**靠 DeX 那边的输入法（和插真键盘一样）：要用支持外接键盘拼音的输入法，比如 Gboard。
- **数字**：数字键盘，也走这块虚拟键盘。
- **贴字**（默认没放在按钮条上，可在设置里分配）：用手机自己的输入法（语音、中文）打一句，按"发送"贴进 DeX。
  原理是先复制到剪贴板再按 Ctrl+V，所以**会覆盖剪贴板原来的内容**。贴字面板开着时触控板暂停（输入法要用触摸）。
- **左键**：按住期间鼠标左键一直按着，配合右手移动就是拖动（像笔记本的实体按键）。

**所有能自定义的位置共用同一份动作清单**：左侧按钮条、按钮条收起后触控板角上的小按钮（左上 / 右上 / 右下；左下 ☰ 固定）、
三指 / 四指手势、键盘最下面一排。清单里有返回、主屏幕、最近任务、切换应用、显示桌面、截屏、复制粘贴撤销、网页前进后退、
开关标签页、方向键、媒体键、键盘界面、数字键盘、旋转、退出等，最后一项"自定义组合键"可以自己勾 Ctrl / Shift / Alt / Win 再挑一个键。

## 安装和启动

需要：电脑上有 adb，手机开了无线调试（或 USB 调试）并已连上。手机有多台时用 `ANDROID_SERIAL` 指定：

```bash
export ANDROID_SERIAL=<手机的 adb 序列号或 IP:端口>
```

第一次装（编译需要 Android SDK，放在项目的 `.sdk/` 下，见 `tools/build.sh` 的报错提示）：

```bash
tools/build.sh --install
```

它会编译、装到手机、并在手机上拉起豆花服务。**手机重启后服务会没掉**，要再运行一次：

```bash
tools/start-server.sh
```

然后在手机上打开"豆花"。第一次打开会问能不能发通知——允许之后，**每次接上外接显示器（有线 DeX、XREAL、无线 DeX）
都会弹一条通知，点一下就在手机上打开豆花**，拔掉显示器通知自动消失（和三星自带触控板的通知一样）。
三星自己的那条通知要是嫌重复，可以在系统通知设置里把它关掉。

触控板底部那行字是状态：

| 状态 | 意思 |
|---|---|
| XREAL One（或你的显示器名） | 一切正常，触摸已接管 |
| 没找到 DeX 屏幕… | 触摸已接管，但 DeX 没在运行 |
| 正在接管触摸屏…… | 刚打开，稍等 |
| 贴字中 · 触控板暂停 | 贴字面板开着 |
| 没连上豆花服务：在电脑上运行 tools/start-server.sh | 服务没起（多半是手机重启过） |

打正式安装包（发给别人装的）：

```bash
tools/package.sh
```

要求先提交（只从最新提交构建），产物在 `dist/douhua-<版本>.apk`，用正式密钥签名、不可调试。
正式签名的密钥库放 `.private/release.keystore`，口令写在 `.env`（模板 `.env.example`），这两样都不进 git，**要自己备份**。
没提交时可以用 `tools/package.sh --snapshot` 试打包。调试版和正式版签名不同，手机上换装要先卸载。

其它脚本：

| 命令 | 作用 |
|---|---|
| `tools/start-server.sh --debug` | 拉起服务并每秒记一行鼠标包统计（查卡顿用），日志在手机 `/data/local/tmp/douhua-server.log` |
| `tools/stop-server.sh` | 停掉服务（触摸屏释放、虚拟鼠标移除） |
| `tools/selftest.sh` | 不开界面测 App 能不能连上服务（屏幕灭着时系统会断后台网络，测不准） |
| `tools/test.sh` | 离线测试（手势识别、多点触控解码、触摸屏查找） |

## 注意

- DeX 设置里的"指针流向手机屏幕"保持**关闭**。开着时虚拟鼠标在 DeX 和手机屏之间切换，有卡死重启的已知问题（scrcpy 社区报告过同样的情况）。
- 豆花打开时，系统里会多出一个叫 Douhua Touchpad 的 USB 鼠标和一个叫 Douhua Keyboard 的 USB 键盘；关掉豆花它们就消失。
- 为什么要接管触摸：手机上开着带"执行手势"权限的无障碍服务（比如 Tasker）时，系统规定同一时刻只认一个输入设备，
  手指和虚拟鼠标会互相打断，光标一卡一卡。接管后系统里只剩虚拟鼠标一个设备。
- 豆花申请了"网络"权限，只用来连本机 127.0.0.1 上的豆花服务，不上网。

## 设置项

| 设置 | 默认 | 说明 |
|---|---|---|
| 光标速度 | 2.0 | 手指每移动 1dp，光标走多少 |
| 加速 | 1.0 | 划得快时额外放大，0 = 不加速 |
| 轻点后马上按住移动 = 拖动 | 开 | 关掉的话单击没有延迟，但不能轻点拖动 |
| 拖动等待时间 | 220 毫秒 | 轻点后等多久看你要不要拖；越长越好触发拖动，单击越迟钝 |
| 滚动速度 | 5 | 1–10 档 |
| 自然滚动 | 开 | 内容跟着手指走（Mac 默认） |
| 双指开合 = 缩放 | 开 | 关掉的话双指只滚动 |
| 左右边缘竖向滚动 / 上下边缘横向滚动 | 开 / 开 | |
| 边缘带宽度 | 28dp | 12–64dp |
| 滚动"咔嗒"震动 | 所有滚动 | 关 / 只在边缘滚动时 / 所有滚动 |
| 长按 = 按下左键 | 开 | 按住多久算长按：默认 450 毫秒 |
| 震动 | 中 | 关 / 小 / 中 / 大 |
